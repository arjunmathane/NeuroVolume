02 / Synthetic survival laboratory

Keep the uncertainty between visits

SYNTHETIC DATA ONLY. The experiment uses 600 invented people. Smaller hippocampal volume is associated with earlier events by construction. This tests the software and provides no evidence about Alzheimer disease or anyone's prognosis.

An event lies between the last unimpaired assessment and the first positive assessment. People without an observed event remain right-censored. This model preserves those bounds instead of inventing exact onset dates.
