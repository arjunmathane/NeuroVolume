# Upload NeuroVolume to GitHub

1. Extract `neurovolume-github.zip`.
2. Create a new GitHub repository named `neurovolume`.
3. Upload the contents of the extracted folder so README.md is at the repository root. Include hidden `.github` and `.gitignore` files; GitHub Desktop can add these reliably.
4. Commit the files. The included GitHub Actions workflow checks the Python models and builds the demo.
5. Use the README as the project landing page and review docs/PROJECT_GUIDE.md before describing your contribution on a resume.

The package includes trained models, the executed notebook, measured results, demo source, tests, and documentation. No original participant workbook or individual prediction records are included. Do not upload the separate local research working directory.

The hosted preview created for this project is private to its owner. It is not a public admissions-reviewer demo link. The GitHub repository can run the demo locally using the README instructions.

## Standalone version
Open standalone/index.html directly in a browser for both studies. It works offline and can be hosted independently. Open neurovolume.code-workspace in VS Code for development. The older private hosted demo still displays phase one only.
