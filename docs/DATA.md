# Data provenance and access

Original source: https://sites.wustl.edu/oasisbrains/home/oasis-2/

Official measurement workbook linked by that page at retrieval (2026-09-06):
https://sites.wustl.edu/oasisbrains/files/2024/03/oasis_longitudinal_demographics-8d83e569fa2e2d30.xlsx

Usage terms and access process: https://sites.wustl.edu/oasisbrains/home/access/

Obtain your own authorized copy under the current OASIS terms. The presence of a public download does not grant permission to relicense or redistribute participant data. Do not upload the original workbook, individual predictions, or participant identifiers to GitHub. If a data-access request is needed, use your own truthful identity and institutional affiliation. This project does not submit requests on your behalf.

The project is for non-commercial academic research. Its code license does not relicense OASIS data. OASIS terms prohibit re-identification and impose use, safeguarding, attribution, and distribution requirements. Review the current agreement directly.

The source workbook contains 373 sessions from 150 people. We use the actual earliest row for each person, preserving missing values rather than borrowing from later visits. The operational target is CDR > 0, not the longitudinal Group label. Actual baseline workbook counts: 65 positive and 85 negative. This is not exactly the clinical diagnostic grouping summarized in the publication.
